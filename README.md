# 《深入理解 AI Agent》重点知识总结

本仓库用于整理《深入理解 AI Agent》各章节中适合复习、背诵和自测的重点知识。

全部章节统一收录在 [`重点知识总结.md`](重点知识总结.md) 中，每章包含：

1. **知识总结**：按知识逻辑整理核心概念、原理、流程、区别和注意事项。
2. **问题**：只保留知识总结中的问题，用于闭卷背诵和自测。
3. **对应章节的问题及答案**：每道习题后紧跟答案，用于检查理解和综合运用能力。

具体整理标准见 [`整理规范.md`](整理规范.md)。
